# Archive

Somente material já `SUPERSEDED`, `DONE` ou histórico deve entrar aqui.

Antes de mover qualquer arquivo:

- conferir referências no repositório;
- atualizar o sucessor/documento canônico;
- atualizar `REGISTRY.md` e `ROADMAP.md`;
- preservar provenance útil;
- não mover evidência canônica para cá apenas por ser antiga.

Arquivar reduz ruído; não deve apagar a história necessária para auditoria.
