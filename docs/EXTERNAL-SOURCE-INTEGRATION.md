# Integração de fontes externas

Intelligence não é uma fonte externa. Sua fonte única, builder e
contratos estão em ordax-os/system/intelligence/ e usam a revisão Git
do próprio OS. O repo antigo mantém exclusivamente o histórico.

Para outras fontes e owners que ainda sejam independentes, consultar
a documentação específica e docs/contracts/repository-ownership.json.
Este documento não autoriza ativação, Stable ou instalação física.
