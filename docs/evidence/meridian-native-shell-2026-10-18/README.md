# Meridian Native Shell — capturas históricas (2026-10-18)

Seis imagens preservadas como **evidência visual histórica** do shell Native do
OrdaX. Este diretório contém capturas, não a fonte da Surface; o owner dos
componentes visuais é `ordaxsystems/ordax-surface`.

A existência de uma captura **não comprova** boot USB físico, integridade de
artefato, assinatura, prontidão do Supervisor ou comportamento da revisão atual.
Não utilizar estas imagens como gate de release, como fixture ativa ou como
especificação da interface vigente.
